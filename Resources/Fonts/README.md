# Bundled fonts

## Share Tech Mono

The membership card shared by onboarding and account settings uses
`ShareTechMono-Regular.ttf` for its numeric join date. The font and its
`ShareTechMono-OFL.txt` license are shipped by the Xcode `Copy Fonts` phase.
`ATSApplicationFontsPath = Fonts` in `PhiBrowser-Info.plist` registers the font.
The card falls back to the system monospace face if it is unavailable.

Source: [Google Fonts, Share Tech Mono](https://github.com/google/fonts/tree/main/ofl/sharetechmono).
